# 测试素材说明

这些文件用于验证「自动归档」的不同功能。里面的人物（林川、阿哲）、相机、日期、事件都是虚构的，可以放心用来测试。

## 使用方式

在应用里点「选择照片文件夹…」，选中下面任意一个子文件夹即可；也可以直接把文件夹拖进窗口。

## 素材说明

- `01`–`03`、`06`–`10` 里的 JPEG 都带 EXIF 拍摄时间、作者、相机和序列号。
- `04` 里的 `export-2.jpg` 特意不带任何 EXIF，`export-1.png` 也不带元数据。
- `05` 和 `10` 里的 MOV / MP4 / MP3 / WAV 是 0 字节占位文件，只用来测试格式分流和「没有拍摄时间时按文件创建时间」的兜底逻辑，不是可播放的视频。
- `10` 里的 `.nef` 是重命名的 JPEG，只用于测试「RAW 按扩展名分流」，不是真正的 RAW。
- `09` 里的 `custom.xyz` 也是重命名的 JPEG；默认不识别，需要先在设置里把 `xyz` 加进「图片」。
- `06` 和 `10` 里的 `.LRF` 是文本占位文件，用于测试大疆预览文件的识别和保留询问。

## 重新生成

在仓库根目录执行：

```bash
clang -fobjc-arc -framework Cocoa -framework ImageIO -mmacosx-version-min=11.0 \
  -o /tmp/mkphotos tools/mkphotos.m
/tmp/mkphotos --fixtures test-fixtures
```

会覆盖同名素材文件，不会动这份说明。

## 01-单人基础

5 张 JPEG，作者都是「林川」，日期跨 2026-05-19 和 2026-05-20。

测试点：

- 读取 EXIF 拍摄时间；
- 自动日期取本批最早的一天（2026-05-19）；
- 单人模式；
- 首次扫描会出现「发现未知作者」，可把「林川」保存成署名规则。

预期：事件文件夹日期为 `26.05.19`，5 张都进 `（原始照片）`。

## 02-多人-双机位

6 张 JPEG：林川用 SONY（3 张），阿哲用 Canon（3 张），同一天拍摄。

测试点：

- 扫描到两位作者时弹「检测到多位作者」，可切换多人模式；
- 多人模式下 `（原始照片）/林川/` 和 `（原始照片）/阿哲/`；
- 两位作者的相机、序列号不同；
- 未知身份弹窗一次列出两行，可分别保存对应关系。

预期：`（原始照片）` 下出现两个人名文件夹，各 3 张。

## 03-无作者-有序列号

3 张 JPEG，没有 Artist，但有 `SONY / ILCE-7M4 / SN-C3`。

测试点：

- 未知身份弹窗会显示「未识别作者 · SONY ILCE-7M4 · SN-C3 · 3 张」；
- 留空保存 → 用 `SN-C3` 作为署名；
- 填写「小林」→ 保存规则，下次同序列号的素材自动用「小林」；
- 取消保存 → 这批仍按「未标注」处理。

## 04-无元数据

`export-1.png` 和 `export-2.jpg` 都没有拍摄时间、作者、相机信息。

测试点：

- 没有拍摄时间时按文件创建时间兜底；
- 多人模式下因为没有身份信息，归入 `未标注`；
- 「文件构成」仍会把它们统计成图片。

## 05-视频与音频

两个视频占位（MOV / MP4）和两个音频占位（MP3 / WAV）。

测试点：

- 视频和音频都进 `（原始视频）`；
- 音频不参与归档日期的计算；
- 「文件构成」显示视频、音频数量；
- 没有视频时不创建 `（原始视频）`（可单独只选 MP3 验证）。

## 06-大疆预览

`DJI_5001.MP4` + `DJI_5001.LRF` + 一张 `DJI_5001.JPG`。

测试点：

- 扫描到 `.LRF` 时弹「发现预览文件」；
- 默认「不保留」：跳过 LRF，不复制、不移动、不删除原件；
- 选「保留」：LRF 跟同名 MP4 一起进 `（原始视频）`，放在同一个文件夹；
- 命令行等价参数：`--keep-preview`。

## 07-日期不一致

两张同作者照片，日期分别是 2026-05-18 和 2026-05-22。

测试点：

- 先扫描整个文件夹，自动日期取 2026-05-18，创建 `26.05.18…`；
- 再只选 `DAY_6002.jpg`（05-22）扫描：日期仍保持 05-18，并弹出「日期不一致」提示，不会改掉已建文件夹；
- 关闭自动日期后，日期可以手动改，扫描不会覆盖。

## 08-重复与重名

```
08-重复与重名/
├── DUP_7001.jpg
├── DUP_7002.jpg
├── A/DUP_7001.jpg        （与根目录同内容、同名）
├── B/DUP_7002.jpg        （同名、不同内容）
└── C/DUP_7001-copy.jpg   （同内容、不同名）
```

测试点：

- `A/DUP_7001.jpg` 与已导入的同名同内容文件 → 跳过重复；
- `B/DUP_7002.jpg` 与已导入的同名不同内容文件 → 自动改名为 `DUP_7002_2.jpg`；
- `C/DUP_7001-copy.jpg` 名字不同 → 正常导入，不算重复。

预期结果里会显示「跳过重复 1 个 · 重名改名 1 个」。

## 09-特殊名称

- `毕业 典礼（合影）1.jpg`：中文、空格、括号；
- `带 空格 的文件 3.jpg`：中文和空格；
- `UPPER.JPG`：大写扩展名；
- `custom.xyz`：默认不识别，测试自定义扩展名。

测试点：

- 文件名原样保留；
- 大写 `.JPG` 也能识别；
- 在设置里把 `xyz` 加进「图片」后，`custom.xyz` 会被当成图片导入；
- 文件夹名/标签里出现特殊字符时的清理逻辑。

## 10-混合格式

`MIX_8001.jpg`、`MIX_8002.png`、`MIX_8003.nef`、`MIX_8004.mov`、`MIX_8005.mp3`、`MIX_8006.lrf`。

测试点：

- 「文件构成」显示 图片 / RAW / 视频 / 音频；
- JPEG、PNG、NEF 进 `（原始照片）`，MOV、MP3 进 `（原始视频）`；
- LRF 触发预览文件询问；
- 同时存在图片和视频时，事件文件夹下两个原始文件夹都会创建。

## 11-多人-无身份混合

2 张有作者的 JPEG（林川 SONY、阿哲 Canon）+ 1 张没有 EXIF 的 PNG + 1 个 MOV + 1 个 MP3（后三个都没有作者、相机、序列号）。

测试点：

- 单人模式下扫描到 2 位作者，提示是否切换到多人模式；
- 切到多人后，「发现未知身份」弹窗会列出 阿哲、林川，以及「无作者信息 · 3 个文件」；
- 给「无作者信息」填一个名字、不勾选「保存对应关系」→ 这 3 个文件进这个名字的二级目录，规则不长期保存；
- 留空直接保存 → 这 3 个文件进 `未标注`；
- 勾选「保存对应关系」→ 以后没有身份信息的素材会自动用这个名字。

预期（不填名字）：`（原始照片）/林川/`、`（原始照片）/阿哲/`、`（原始照片）/未标注/`；`（原始视频）/未标注/`。

## 12-按文件夹归类

```
12-按文件夹归类/
├── 林川/
│   ├── A_9201.jpg   （作者 林川）
│   └── A_9202.jpg   （无任何信息）
├── 阿哲/
│   ├── B_9301.jpg   （作者 阿哲）
│   └── B_9302.jpg   （无任何信息）
└── 合影/
    ├── C_9401.jpg   （作者 林川）
    ├── C_9402.jpg   （作者 阿哲）
    └── C_9403.jpg   （无任何信息）
```

测试点：

- 单人模式扫描到 2 位作者 → 切换多人模式；
- 「发现未知身份」里，每个有未标注文件的文件夹占一行：`林川`、`阿哲` 会预填对应人名，`合影` 留空（里面有两位作者）；
- 顶部「根据上级文件夹分类未标注文件」默认勾选；
- 点「保存并应用」后弹出确认，列出 `林川/A_9202.jpg`、`阿哲/B_9302.jpg` 被按文件夹归类；
- 确认框里选「改为未标注」可整批撤回；
- `合影/C_9403.jpg` 因为文件夹里有两位作者，不推断，归入你填的名字或 `未标注`。

预期：`（原始照片）/林川/` 3 张（A_9201、A_9202、C_9401），`阿哲/` 3 张（B_9301、B_9302、C_9402），`未标注/` 1 张（C_9403）。

> 注意：这些文件夹分组和确认弹窗只在**多人模式**下出现。如果当前事件文件夹已经创建、并且锁定在单人模式，扫描不会再把模式切到多人；请换一个新的日期/事件，或先删除旧事件文件夹，再扫描第 12 组。

## 13-确认弹窗专用

只有两个单人文件夹，最适合验证「保存后弹出确认」：

```
13-确认弹窗专用/
├── 林川/
│   ├── LIN_0001.jpg   （作者 林川）
│   └── LIN_0002.jpg   （无任何信息）
└── 阿哲/
    ├── ZHE_0001.jpg   （作者 阿哲）
    └── ZHE_0002.jpg   （无任何信息）
```

步骤：

1. 换一个没创建过的事件/日期，避免人员模式被锁定；
2. 选择 `13-确认弹窗专用`，扫描到两位作者时切换多人模式；
3. 未知身份弹窗里应该有 4 行：阿哲、林川，以及两个「无作者信息」行（分别预填 阿哲、林川）；
4. 点 **「保存并应用」**（不是取消）；
5. 应弹出确认，列出：
   - 阿哲（1 个）· ZHE_0002.jpg
   - 林川（1 个）· LIN_0002.jpg

这个组没有多人文件夹，所以不会出现空的「未标注」行；如果它仍然不弹确认，就不是素材问题，而是按钮/版本/模式状态的问题。
